# BakeCraft

Customizable bakery mobile app prototype — Group Assignment IV-a, INSY 8313 (MIS), Adventist University of Central Africa.

Design a cake or pastry for an event (birthday, wedding, corporate) tier by tier, see a live price and preview, and track your order from "confirmed" to "delivered."

## How the screens were made

`wireframes.html` and `high-fidelity.html` are self-contained HTML/CSS files, built so each phone screen imports as a clean, editable Figma frame using the **html.to.design** plugin. Open either file in a browser to preview all screens at once, or import directly into Figma. Full import steps are in `documentation.md` §10.
